# ASCII-Craft

Tarayıcıda çalışan ASCII görünümlü blok arena PvP prototipi.

## Çalıştırma
- `index.html` dosyasını tarayıcıda aç.
- GitHub Pages için repository Settings → Pages → Deploy from a branch → `main` / `/(root)` seç.

## Kontroller
- WASD veya ok tuşları: hareket
- Fare: nişan
- Sol tık / Space: saldırı
- H: iksir
- Her rakip yenildiğinde Excel, Scratch, web ve dijital güvenlik konularından bir soru çıkar. Doğru cevap bir geliştirme verir.

## Notlar
- Tek dosyalı HTML/CSS/JavaScript projesidir; harici kütüphane yalnızca isteğe bağlı PeerJS çok oyunculu bağlantısı için yüklenir.
- Multiplayer bölümü deneysel prototiptir, tam senkronize rekabetçi sunucu altyapısı değildir.
- Minecraft, Mojang Studios'un ticari markasıdır. Bu proje hayran yapımıdır ve Mojang/Microsoft ile bağlantılı değildir.
